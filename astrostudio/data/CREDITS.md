# Bundled catalog credits

`astrostudio/data/openngc_hints.json` is derived from **OpenNGC** by Mattia Verga
(https://github.com/mattiaverga/OpenNGC), released under **CC BY-SA 4.0**.
The full license text is in `LICENSES/OpenNGC-CC-BY-SA-4.0.txt`.

OpenNGC merges data from NED (NASA/IPAC), HyperLEDA, SIMBAD (CDS), HEASARC and
Harold Corwin's NGC/IC positions. Those sources are credited in the OpenNGC README.
Fields derived from OpenNGC remain under CC BY-SA 4.0; share-alike obligations apply
to redistributions of the derived catalog file.

The bundled file is a compact projection containing only J2000 coordinates, catalog
designations and common names needed for filename-driven plate-solving hints. It is
used locally and never sent to a network service by AstroStudio.
